## Projects

### [Task Tracker](https://github.com/zeinamagdy-gif/TaskTracker)
A command-line to-do app in Python. Add, update, and delete tasks, set their status to todo, in-progress, or done, and keep everything saved in a JSON file between runs.

**Uses:** Python, classes, JSON, file handling

### J.A.R.V.I.S. Voice Assistant
A Windows voice assistant with an animated sci-fi HUD. Say "Jarvis" to control music, open apps, check the weather, search the web, or chat with a local AI model.

**Uses:** Python, pygame, speech recognition, Ollama, gTTS
